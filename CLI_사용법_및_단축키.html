초보자 맞춤 학습 가이드

💻 CLI 사용법 및 필수 단축키

마우스 대신 키보드로 컴퓨터와 빠르게 소통하는 비밀 꿀팁 총정리!

🧭 1. CLI란 무엇인가요? (식당 비유 🍽️)

🖱️ GUI (평소 사용하는 방식)

마우스로 폴더 아이콘을 더블 클릭하고 창을 엽니다.
식당 키오스크 화면을 손가락으로 꾹꾹 누르는 것과 같습니다.

⌨️ CLI (개발자의 방식)

검은 화면(터미널)에 명령어를 글자로 칩니다.
식당 점원에게 "김치찌개 하나 주세요" 하고 말(글자)로 주문하는 것과 같습니다.

💡 왜 쓸까요? 마우스로 10번 클릭해야 할 복잡한 작업도, 명령어 한 줄로 1초 만에 끝낼 수 있고 AI가 컴퓨터를 조작할 때 가장 정확하기 때문입니다!

📂 2. 꼭 알아야 하는 기본 명령어 6가지

dir 현재 폴더 내용물(파일 목록) 보기

🔍 "지금 내가 서 있는 이 방(폴더)에 무슨 서랍과 파일이 있나요?" 하고 확인하는 명령어입니다.

cd day1 원하는 폴더 안으로 쏙 들어가기

🚪 Change Directory의 약자. "day1이라는 방 문을 열고 안으로 들어갑니다."

cd .. 뒤로 가기 (상위 폴더로 빠져나오기)

🔙 점 두 개(..)는 부모 폴더를 뜻합니다. 탐색기의 [뒤로 가기] 버튼과 같습니다.

mkdir test 새 폴더 만들기

📁 마우스 우클릭 후 [새로 만들기] → [폴더]를 누르는 것과 똑같습니다.

cls 화면 깨끗하게 지우기 (청소)

🧹 글자가 너무 많아 어지러울 때, 칠판을 지우개로 싹 지우고 맨 위로 올려줍니다.

explorer . 강력 추천 꿀팁 ⭐ 현재 폴더를 윈도우 창으로 바로 열기!

✨ 점 하나(.)는 '현재 위치'를 뜻합니다. 지금 있는 폴더를 내 눈앞에 윈도우 파일 탐색기 창으로 짠! 하고 열어줍니다.

⚡ 3. 작업 속도 3배 올려주는 마법의 단축키

Tab 파일명 자동 완성 (최고의 꿀팁!)

긴 파일명을 다 칠 필요 없이 앞 글자(예: qu)만 치고 Tab을 누르면 quiz.html이 자동으로 완성됩니다. 오타 걱정 제로!

↑ 이전 명령어 다시 부르기

방금 입력했던 긴 명령어를 키보드 위 화살표 ↑ 하나로 다시 불러옵니다. 똑같은 걸 두 번 칠 필요가 없습니다.

Ctrl + C 긴급 정지 (작업 취소)

명령어가 멈추지 않고 계속 돌거나 취소하고 싶을 때 누르면 "지금 하던 거 즉시 멈춰!" 하고 빠져나옵니다.

Shift + Enter AI 대화창 줄바꿈

AI 비서에게 질문을 보낼 때 엔터만 치면 전송되어 버리지만, Shift를 누르고 Enter를 치면 여러 줄로 편하게 작성할 수 있습니다.

🌐 4. 웹 실습할 때 꼭 알아야 할 브라우저 비밀 키

Ctrl + Shift + R 강력 새로고침 (하드 리프레시)

브라우저는 속도를 빠르게 하려고 이전 사진과 코드를 컴퓨터에 몰래 저장(캐시)해 둡니다. 코드를 고치고 F5를 눌러도 안 바뀔 때, Ctrl + Shift + R을 누르면 "옛날 기억 싹 지우고 방금 고친 새 코드로 전부 다시 불러와!" 하고 진짜 최신 화면을 띄워줍니다!

F12 개발자 도구 (Console 에러 확인)

버튼을 눌렀는데 화면에 아무 반응이 없거나 코드가 틀렸을 때, F12를 누르고 상단의 [Console] 탭을 누르면 빨간 글씨로 어디가 틀렸는지 원인을 친절하게 알려줍니다.

단축키와 CLI를 내 손에 익히면 AI 코딩이 훨씬 더 쉽고 재미있어집니다! 🚀
