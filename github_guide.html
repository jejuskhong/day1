세상 모든 코드가 모이는 곳,
깃허브(GitHub) 완벽 가이드

혼자 공부한 코드 저장부터 전 세계 개발자와의 협업, 그리고 AI 도구(안티그래피티)와의 결합까지! 어렵게만 느껴졌던 깃허브를 가장 쉽고 명쾌하게 안내해 드립니다.

💡 깃허브란 무엇인가요?

DEFINITION & ANALOGY
☁️

1. 클라우드 외장하드

컴퓨터가 고장 나거나 자리를 옮겨도 언제 어디서나 내 코드를 안전하게 내려받을 수 있는 무료 백업 금고입니다.

⏳

2. 코드 타임머신

"어제 작동하던 코드가 왜 안 되지?" 할 때, 1초 만에 어제 작성했던 상태로 되돌릴 수 있는 완벽한 이력 관리 도구입니다.

🌐

3. 개발자의 인스타그램

내가 공부하고 만든 웹사이트와 프로그램을 세상에 자랑하고, 남들에게 포트폴리오로 보여줄 수 있는 최고의 공간입니다.

🚀 깃허브 핵심 사용법 4단계

HOW TO USE STEP-BY-STEP
1

저장소 만들기

우측 상단 [New] 버튼을 눌러 프로젝트를 담을 폴더(Repository)를 만듭니다.

2

파일 추가하기

[Add file] → [Upload files]로 내가 만든 HTML이나 이미지 파일을 드래그해서 올립니다.

3

커밋(저장 도장)

어떤 내용을 바꿨는지 메시지를 적고 [Commit changes]를 누르면 기록이 영구 저장됩니다.

4

무료 웹사이트 배포

저장소 Settings → Pages에서 브랜치를 켜면 전 세계 누구나 접속할 수 있는 웹사이트가 됩니다!

⚖️ 깃허브의 장점과 단점

PROS & CONS

✅ 깃허브의 핵심 장점

  • 평생 무료 백업: 전 세계 어디서든 내 소스코드를 안전하게 보관할 수 있습니다.
  • 초강력 버전 복원: 과거의 모든 수정 내역이 남아 실수해도 즉시 되돌립니다.
  • 무료 웹사이트 호스팅: GitHub Pages로 내 포트폴리오 사이트를 0원에 엽니다.
  • 잔디 심기 성취감: 공부한 날마다 초록색 잔디가 심어져 동기부여가 됩니다.
  • 글로벌 포트폴리오: 이력서 링크 하나로 나의 실력과 성실함을 증명합니다.

⚠️ 주의해야 할 단점

  • 낯선 용어 장벽: Commit, Push, PR 등 생소한 개념을 초기에 익혀야 합니다.
  • 대용량 파일 제한: 파일 1개당 100MB가 넘어가면 기본 방식으로 업로드되지 않습니다.
  • 코드 충돌 가능성: 같은 줄을 여러 명이 동시에 고치면 충돌(Conflict)이 발생합니다.
  • 보안 실수 주의: 비밀번호나 개인정보를 올리면 전 세계에 노출될 위험이 있습니다.
  • 영어 인터페이스: 메뉴와 오류 메시지가 영문으로 제공되어 익숙해짐이 필요합니다.

🛡️ 반드시 지켜야 할 유의사항 5대 원칙

SECURITY & BEST PRACTICES

🚨 꼭 기억해 주세요!

  • 1. API 키 및 비밀번호 절대 업로드 금지: OpenAI API 키나 비밀번호가 적힌 파일은 절대 올리면 안 됩니다. (자동 해킹 봇이 1초 만에 찾아냅니다!)
  • 2. 100MB 이상 대용량 파일 피하기: 영상이나 거대한 압축 파일은 일반 깃 푸시가 막힙니다.
  • 3. 공개(Public) / 비공개(Private) 설정 확인: 개인 일기나 시험 답안처럼 나만 봐야 하는 파일은 Private으로 만드세요.
  • 4. 알아보기 쉬운 커밋 메시지 쓰기: "111", "수정" 대신 "메인 배너 변경", "테트리스 추가"처럼 알아보기 쉽게 적어주세요.
  • 5. 작업 전 최신 파일 받아오기(Pull): 다른 컴퓨터에서 고친 내용이 있다면 항상 먼저 받아온 후 작업을 시작하세요.

🎁 AI 비서가 강력 추천하는 깃허브 꿀팁 3가지

SPECIAL PRO TIPS
✨

꿀팁 1: 깃허브 프로필을 특별하게 꾸미는 비법 (README.md)

깃허브에서 내 아이디와 완전히 똑같은 이름의 저장소(예: jejuskhong/jejuskhong)를 만들고 README.md를 작성하면, 내 프로필 대문에 나만의 멋진 소개 카드와 방문자 수 배지가 나타납니다!

🌍

꿀팁 2: GitHub Pages로 0원에 나만의 포트폴리오 사이트 열기

오늘 만든 index.html 파일을 저장소에 올린 후, Settings → Pages → Branch를 'main'으로 선택하고 Save를 누르면 https://내아이디.github.io/저장소이름 형태의 진짜 전 세계 웹사이트 주소가 무료로 생깁니다!

🤖

꿀팁 3: 안티그래피티에게 말 한마디로 깃 관리 부탁하기

복잡한 깃 명령어를 일일이 외우지 않아도 됩니다. "오늘 작업한 내용 예쁘게 커밋해서 푸시해줘"라고 한마디만 부탁하면 안티그래피티가 알아서 상태를 점검하고 안전하게 업로드해 드립니다.
