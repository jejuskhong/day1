💬 단계별 작업 진행 내역

1단계 : 첫 번째 자기소개 웹페이지
요청: index.html 파일 하나로 이름(홍수경), 한 줄 소개, 신청 이유, 관심사 카드 3개(감귤 주황색), 공감 카운터 버튼 만들기
✅ 결과: 모바일 반응형 감귤 테마 웹페이지 생성 및 1씩 올라가는 공감 버튼 구현 완료
2단계 : 두 번째 버전 & 밤 모드 기능
요청: index_1.html 파일 하나로 새로운 한 줄 소개, 한라산 숲 초록색 테마, 오른쪽 위 밤 모드 버튼 넣기
✅ 결과: 숲 초록색 테마 제작 및 클릭 시 다크 테마(밤/낮)로 부드럽게 토글되는 기능 완성
3단계 : 카드 애니메이션 및 인사말
요청: index.html에서 관심사 카드에 마우스 올리면 살짝 커지게 하고, 맨 아래 '만나서 반갑습니다' 문구 추가
✅ 결과: 마우스 오버 시 부드러운 확대(scale) 효과 및 하단 주황색 인사말 상자 추가
4단계 : 맑은 에메랄드빛 바다 이미지 적용
요청: 제주 자연 풍경 무료 이미지로 배너를 채워줘
✅ 결과: 인물 없는 투명한 에메랄드빛 바다 사진(jeju_beach.jpg)을 로컬에 저장하여 상단 배너로 완벽 연결
5~6단계 : 제주 상식 퀴즈 & 정답 판정
요청: quiz.html 만들기 (오류 찾기 실습용 실수 포함) → 답 입력창 넣기 → 정답/오답 표시하기
✅ 결과: 입력창과 엔터키 지원, '한라산' 입력 시 정답(초록), 오답 시 붉은 상자가 나타나는 판정 기능 완성

💡 브라우저 핵심 단축키 팁

  • F5 일반 새로고침 (웹페이지 내용 다시 읽기)
  • Ctrl + Shift + R 강력 새로고침 (코드나 이미지가 안 바뀔 때 캐시를 완전히 비우고 새로고침)
  • F12 개발자 도구 (Console 탭에서 코드 에러 메시지 확인하기)
